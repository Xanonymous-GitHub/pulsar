## Keeping AGENTS.md current

AGENTS.md is the single source of truth for project instructions (shared with other coding agents). Do not duplicate its content here.

- When you learn something durable and non-obvious about this project (build quirks, hardware gotchas, config that must exist, commands that differ from defaults), add it to the "Project learnings" section of AGENTS.md before finishing the task. Make the edit without waiting to be asked, and mention it in your summary.
- Do not record what the code, `Cargo.toml`, or git history already shows, and do not record machine-specific paths (e.g. `eim_config.toml` contents).
- Do not edit the generated sections ("Project-specific notes", "Useful references"); extend them only by adding to "Project learnings".
- Keep AGENTS.md short: one line per learning, remove entries that become false, and merge duplicates.
